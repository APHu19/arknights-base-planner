# 基建排班自主枚举器（planner）

> **本项目完全由 DSH（DeepSeek Harness）生成**：全部代码、数据抽取脚本、规则表、求解器、GUI、自检与文档均由 DSH 在本工作区内自动编写与迭代，未使用手写代码或第三方框架（GUI 用 Python 自带 Tkinter）。

一句话：**给布局与诉求，自动枚举出六班排班表，并直接输出可导入 MAA 的 JSON。**

## 快速开始

```powershell
python planner\gui\app.py                                   # 图形界面（四页签）
python planner\cli.py solve --main lmd --gold no_deficit --layout 333 --out planner\out
python planner\cli.py solve --list                          # 全部目标维度与各布局电力
python planner\cli.py selftest                              # 25 条自检
```

## 关键可选参数

| 参数 | 说明 |
| --- | --- |
| `--storage off/warn/clip` | 制造站爆仓策略（默认 `warn`）：所有制造站都检测，**仅班次 ≥6h 执行**；`clip` 会把超容量产出剪掉并如实扣 KPI |
| `--shift-hours 4/6/8/12` | 每班时长；班次数 = 24÷时长（4h→6 班、6h→4 班）。⚠ 非 4h 班次结构的寝室/心情**尚未校验** |
| `--clue-weight 0` | 信用/线索折算开关（默认 0 = 不影响排班，只在结果里显示"会客室线索 X 份/天"） |
| `--morale 12/16/20` | 心情底线硬约束 |
| `--width/--topk/--rounds/--fast` | 求解精度与耗时权衡 |

## 已知问题（诚实清单，详见 SKILL.md §7）

- 非 4h 班次表：能生成班次与做爆仓检测，但**寝室/心情尚未调优**（6h×4 班实测最低心情 0.0）
- 无人机未做逐班次精确分配；求解器为启发式（无全局最优证明）
- 本地 dump 里合作活动干员星级已确认无需修正（`虎狼丸` 就是 1★）；会客室的宿舍氛围加成**已含在基础 126% 里**，不再另加；线索未折算成信用（`--clue-weight` 默认 0）

## 已验证的关键事实

- 所有订单档的**龙门币/赤金恒为 500** → 赤金无"性价比"差异，瓶颈是**每格产能**与**金条预算**
- 但书违约档 = **6.64 币/效率点·h**；非但书队伍此前被高估 **55%**
- 333 龙门币上限 ≈ **45,000/天**（产金 ~91/天 × 500）
- 技能受**精英化阶段**门控（明椒 E0=裁缝·α、E2=裁缝·β；森蚺 E0=自动化·α、E2=β）
- 心情三类修正（自身 / 房间全员 / 房间**其他**）、中枢减压**取最高**、同族技能**不叠加**
- 深海猎人加成属**房间效率**、按制造站内人数计、同站多人只算一次
- 无人机：**1 架 = 3 分钟基础耗时**；充能基础速率是**全局 10 架/h**
- 会客室：每份线索基础 **20 小时**；`总速度% = 126 + Σ干员(星级 4★+2/5★+4/6★+5) + 精英化(精1+8/精2+16) + 未红脸+5 + Σ后勤技能%`（**加算**）
  → 本池最佳 `伊内丝+红` = 230% = **3.96 份/天**；体系占位队 `余+望` = 178% = 3.34 份/天
